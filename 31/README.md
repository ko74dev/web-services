# FastAPI + Jinja2 Веб-приложение

Это простое веб-приложение, созданное с использованием FastAPI и шаблонизатора Jinja2. Оно принимает параметр `name` из адресной строки и отображает приветственное сообщение с использованием переданного имени.

## Требования

- Python 3.8+
- FastAPI
- Uvicorn
- Jinja2

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта в нужную директорию.

2. Создайте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:
   - На Windows:
     ```bash
     venv\Scripts\activate
     ```
   - На macOS/Linux:
     ```bash
     source venv/bin/activate
     ```

4. Установите необходимые зависимости:
   ```bash
   pip install fastapi uvicorn jinja2
   ```

## Запуск приложения

Для запуска приложения в режиме разработки с автоматической перезагрузкой при изменении кода, выполните:

```bash
uvicorn main:app --reload
```

Приложение будет доступно по адресу: `http://localhost:8000`

## Использование

После запуска приложения вы можете посетить следующие URL:

- `http://localhost:8000/` - отобразит приветствие с именем по умолчанию "Гость"
- `http://localhost:8000/?name=Иван` - отобразит приветствие с именем "Иван"
- `http://localhost:8000/?name=Анна` - отобразит приветствие с именем "Анна"

### Описание файлов:

- **`main.py`**: Содержит логику приложения FastAPI, включая инициализацию шаблонизатора Jinja2 и определение эндпоинта `/`.
- **`templates/index.html`**: HTML-шаблон, который использует синтаксис Jinja2 для отображения имени пользователя через переменную `{{ username }}`.
- **`templates/`**: Папка, в которой хранятся все HTML-шаблоны. FastAPI использует эту папку для поиска файлов при рендеринге ответов через Jinja2Templates.

## Дополнительные возможности

Шаблонизатор Jinja2 поддерживает множество возможностей, таких как:
- Условные конструкции: `{% if condition %}...{% else %}...{% endif %}`
- Циклы: `{% for item in items %}...{% endfor %}`
- Фильтры: `{{ variable | filter }}`
- Макросы и включаемые файлы

Для получения дополнительной информации о возможностях Jinja2 посетите [официальную документацию](https://jinja.palletsprojects.com/).
