# FastAPI Web Application with Jinja2 Templates

Веб-приложение на FastAPI с рендерингом HTML-шаблонов через Jinja2.

## Особенности

- Эндпоинт `GET /`, который рендерит HTML-шаблон через Jinja2
- HTML-шаблон `index.html` выводит список задач циклом
- Конфигурационный файл `.env.example` для настроек приложения

### Пояснения:
1. Эндпоинт `GET /` — это «входная дверь» на ваш сайт. 
   - GET означает действие «получить страницу».
   - / (слэш в конце) означает главную страницу сайта (самую первую, которую вы видите, когда заходите на сайт 
   по адресу вроде http://localhost:8000/).
   - Вместе GET / — это команда: «Когда кто-то заходит на главную страницу сайта, сделай следующее».
2. HTML-шаблон — это «каркас» или «черновик» страницы сайта. 
   - Представьте себе пустую анкету, где есть графы «Имя», «Возраст», «Статус». Сам по себе этот бланк не содержит конкретных данных. HTML-шаблон — это такая же «заготовка» страницы, в которой есть структура (заголовки, списки, кнопки), но нет конкретных данных, которые должны быть на ней.
3. Рендеринг через Jinja2 — это процесс «заполнения» этой заготовки реальными данными.
   - Jinja2 — это специальный инструмент (библиотека) для Python, который берет HTML-шаблон и подставляет в него нужные данные (например, список задач, имя пользователя или дату).


## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install fastapi uvicorn jinja2
   ```

2. Запустите приложение с помощью uvicorn:
   ```bash
   uvicorn main:app --host 127.0.0.1 --port 8000 --reload
   ```

3. Откройте в браузере:
   - `http://localhost:8000/`
   - или `http://127.0.0.1:8000/`

## Технические детали

- Приложение использует `jinja2.Environment` с `FileSystemLoader` для рендеринга шаблонов
- Кэширование шаблонов отключено для корректной работы с динамическими данными
- Сервер запускается через `uvicorn` с поддержкой автоперезагрузки при изменениях кода
