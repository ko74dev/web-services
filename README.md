# FastAPI Server - Вайб-Кодер

Простой API-сервер на Python с использованием библиотеки FastAPI.

## Установка зависимостей

Перед запуском сервера необходимо установить необходимые зависимости:

```bash
pip install fastapi uvicorn
```

## Запуск сервера

Запустите сервер командой:

```bash
uvicorn main:app --reload
```

После запуска сервер будет доступен по адресу: `http://localhost:8000`

## Эндпоинты

### GET /user

Возвращает информацию о пользователе в формате JSON:

**Ответ:**
```json
{
  "status": "success",
  "name": "Вайб-Кодер",
  "role": "Архитектор"
}
```

**Пример запроса:**
```bash
curl http://localhost:8000/user
```

## Документация API

FastAPI автоматически генерирует интерактивную документацию к API:

- **Swagger UI:** `http://localhost:8000/docs`
- **ReDoc:** `http://localhost:8000/redoc`

Эти страницы позволяют просматривать доступные эндпоинты и тестировать запросы напрямую из браузера.
